# My Prompts About class note - example

## A. 摘要 Prompt
- 背景: 下面是一段我的课堂笔记文本：<粘原文>
- 目标: 生成一段不超过 100 字的中文摘要，便于 2 分钟复习。
- 约束: 使用简洁句子，避免引入新概念。
- 输出格式: 一句话 + 3 个要点（Markdown 列表）。
- 实例：🥇下面是我自己整理的课堂笔记 请根据图片进行摘要 不要参考外部资源，使用简明中文字体，字数限制在200字以内 输出为Markdown格式 (未能输出为markdown格式）🥈修改摘要条件为：1，一句话总结 2，三个要点 3，一个可执行的步骤清单。再次强调输出格式为：Markdown格式（未能实现输出格式） 🥉直接输出markdown格式文本供我复制到.md文件里(成功输出为markdown格式）

## B. 练习题 Prompt
- 背景: 同上（课堂笔记）
- 目标: 根据笔记生成 5 道选择题（每题4个选项，标注正确答案）。
- 约束: 难度为高中程度，覆盖笔记重点。
- 输出格式: 编号选择题 + 答案列表。
- 实例: 1.再根据图片出一道相关的题目 难度为高中水平 无字数限制 题目完整清晰 输出为可供复制的Markdown格式 2.给出参考答案 3.答案后附解析 按照做题模板分析题目

## C. 速查卡片 Prompt
- 背景: 同上（课堂笔记）
- 目标: 抽取 6 个关键概念，每个概念写出 1 行定义与 1 个例子。
- 约束: 每个定义不超过 30 字。
- 输出格式: 概念 - 定义 - 例子（表格或 Markdown 列表均可）。
- 实例:根据图片制作速查卡片 以挖空的形式来检查相关做题步骤的记忆 要点要全，方法全部来自笔记，不引入外部资源，无字数限制，输出为Markdown格式以供复制
