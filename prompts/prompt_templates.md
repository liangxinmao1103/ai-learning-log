# Prompt 模板（四要素）

## 模板格式
- 背景（context）: 一句话说明相关背景或输入来源。
- 目标（goal）: 明确要 AI 完成的主要任务。
- 约束（constraints）: 字数限制 / 风格 / 不使用外部信息 等。
- 输出格式（output format）: 列表/JSON/Markdown/标题+要点 等。

## 示例：学习笔记自动摘要
- 背景: 下面是我整理的一段课堂笔记（文本）。
- 目标: 生成一段一目了然的学习摘要，便于复习。
- 约束: 不超过 120 字，使用简明中文；列出 3 个要点。
- 输出格式: Markdown 列表（每点一行）。

## 示例：代码错误定位（debug）
- 背景: 下面是一段 Python 报错信息与相关代码片段。
- 目标: 指出最可能的三种错误原因并给出一个修复建议。
- 约束: 每条原因不超过 25 字，建议要有可执行的修复步骤。
- 输出格式: 有序列表（原因 + 修复步骤）。
